# Saved Lasair ZTF payloads

Put saved JSON responses in the folder named for the endpoint that produced
them. These fixtures support repeatable payload-contract inspection; they are
not live API tests and require no credentials.

Never commit API tokens or other credentials. Do not commit large or private
payloads unless they have been deliberately anonymized and their inclusion is
intentional. Prefer filenames that identify the object (for example,
`ZTF20acpwljl.json`) or clearly state the endpoint purpose.
